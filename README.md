# Student Marks Ranking System using NumPy

## 📌 Project Description
This project is a student marks ranking system built using Python and NumPy.
It calculates total marks, percentage, grade, and rank for each student based on their exam scores.

## 🛠️ Technologies Used
- Python
- NumPy
- Jupyter Notebook / PyCharm

## 📊 Features
- Calculates total marks for each student
- Computes percentage
- Assigns grades (A, B, C, Fail)
- Generates student ranking based on percentage
- Displays a final student performance report

## 📂 Dataset
Marks of students stored in a NumPy array (students × subjects).

Example:
- 5 students
- 3 subjects per student

## ▶️ How to Run the Project
1. Install Python
2. Install NumPy:
   pip install numpy
3. Open the project in PyCharm or Jupyter Notebook
4. Run the Python file or Notebook
